# VideoArgus — pip dependencies (pip fallback; see environment.yml for the conda route).
#
# Install torch FIRST, matching your CUDA. The CV tools (SAM3 / UniPercept / DINOv3 / Depth-Anything)
# are validated on torch 2.8.0 — pin it explicitly rather than letting pip pull the newest build
# (2.10+ often outpaces driver/tool support). torch 2.8.0 ships on the cu126 / cu128 wheel indexes
# (NOT cu124, which stops at 2.6.0); its CUDA 12.6 runtime works on 12.x drivers. E.g.:
#
#   pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu126
#
# (swap cu126 -> cu128 for newer drivers), then: pip install -r requirements.txt
#
# The vendored CV-tool source is fetched by setup_tools.py: SAM3 is editable-installed (`pip install
# -e tool_models/sam3`) so `import sam3` resolves; UniPercept is added to sys.path at runtime. Neither
# is on PyPI, so neither is listed below.
